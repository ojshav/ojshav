## 👨‍💻 About Me

I'm a Product Engineer who enjoys solving engineering problems more than chasing specific technologies.

Over the last few years I've worked across the complete product lifecycle—designing APIs, building backend services, developing frontend applications, deploying infrastructure on AWS, and maintaining production systems.

Most of my work revolves around:

- Building scalable backend services with **NestJS**, **Python**, and **Node.js**
- Developing modern web applications using **React** and **Next.js**
- Designing databases with **PostgreSQL**, **MongoDB**, and **Redis**
- Deploying applications using **Docker**, **Linux**, and **AWS**
- Building AI-powered features using **LangChain**, **RAG**, and modern LLMs

I like understanding how systems work internally and continuously look for ways to simplify architecture, improve developer experience, and ship reliable software.
